结构化表格证据（Docling + PyMuPDF）
点击单元格 → 将 单元格文本 + 页码 + bbox 作为当前参数的证据写入右栏（PDF 会高亮该单元格）。合并单元格标有 ⧉。
科学公式证据（视觉重建 + SymPy）
扫描截图中重建的公式由 Agent 填写 sympy 表达式，SymPy 校验解析/变量/数值/量纲。VALIDATED 只代表数学自洽，与论文一致需人工核对截图后点击“核对无误”。
科研曲线数字化（WebPlotDigitizer 思路）
在图上点击轴参考点（每轴 ≥2 个已知刻度），输入对应数值 → 预览换算曲线 → 确认后生成 CSV 并可绑定到当前函数参数（如 OCP）。人工点击是标定生效的唯一途径。
